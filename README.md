# Getting Started PhotoGrid

The app has following functionalities:

1. Photos displayed in Masonry Grid Layout

2. Infinite scroll fetching based on Intersection observer. Renders only 20 items in the beginning.

3. Search function

4. Photo Details Page

5. Back Button that takes you to home page.

6. Tests

Tools and technologies decisions:

This project was bootstrapped with [Create React App](https://github.com/facebook/create-react-app). I wanted to use NextJS as it comes with it's own router, image optimization, api related changes etc. However, it was specifically mentioned in the assignment to configure react router dom and avoid using any frameworks. So, i went ahead with a bare minimum tech to showcase my skills. I have used styled components for css. React testing library for tests.

It's built on React 19 and React Router Dom 6.22.0.
